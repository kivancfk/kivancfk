## 🚀 Featured Projects

### **RiskFlow — Payment-Risk ELT Platform**
End-to-end payment-risk data platform using a modern data stack.

`PySpark` · `Airflow` · `dbt` · `Kafka` · `PostgreSQL` · `Great Expectations`

- Built a medallion-style ELT architecture: **bronze → silver → gold**.
- Designed transformation layers for payment, customer, transaction, and risk-analysis datasets.
- Added data-quality gates to validate schema, nulls, duplicates, and business rules.
- Created analytics-ready marts for payment-risk monitoring and reporting.

### **RiskFlow PayGuard — Real-Time Fraud Scoring**
Real-time ML scoring service for fraud-risk decisions.

`FastAPI` · `LightGBM` · `SHAP` · `scikit-learn` · `Docker`

- Built an API service returning **allow / review / block** decisions.
- Used calibrated LightGBM probabilities for fraud-risk scoring.
- Added SHAP-based explanations to make model decisions more interpretable.
- Designed the service with production-style API structure and deployment readiness.

### **chAInSight — Supply Chain Optimisation Platform**
Full-stack inventory and transportation optimisation platform built for Eczacıbaşı VitrA.

`PostgreSQL` · `Django` · `React` · `SQL` · `Optimization`

- Designed normalized PostgreSQL schemas and advanced SQL workflows.
- Built backend APIs for inventory simulation, production scheduling, and transportation optimisation.
- Developed React views for Excel uploads, variable updates, dashboards, and archive access.
- Supported 14-week stock prediction, critical item detection, and truck/ship transport recommendations.

### **Spotify Hit Predictor**
Machine learning project predicting whether a track becomes a commercial hit.

`R` · `tidymodels` · `glmnet` · `XGBoost` · `ROC-AUC`

- Built a supervised classification model using 40k+ Spotify tracks.
- Cleaned and combined decade-level datasets into a unified modelling dataset.
- Compared regularised logistic regression and XGBoost.
- Evaluated performance using ROC-AUC, PR-AUC, accuracy, and F1.
